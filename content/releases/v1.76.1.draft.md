Don't forget to mark the static binary executable:
```
chmod +x vg
```
**Docker Image:** `quay.io/vgteam/vg:v1.76.1`

**Buildable Source Tarball:** [vg-v1.76.1.tar.gz](https://github.com/vgteam/vg/releases/download/v1.76.1/vg-v1.76.1.tar.gz)

Includes source for vg and all submodules. **Use this instead of Github's "Source Code" downloads**; those will not build as they do not include code for bundled dependencies that the `vg` build process needs.

This release includes:

* Revert back to elftools submodule (instead of system install) in order to fix static build.
* gref vcfs now compatible with vcfbub via fixed LV symantics.
* unused contigs omitted from VCF headers
